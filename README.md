# pvtmb

Material balance and PVT calculator for black-oil reservoirs.

Work in progress:

- black-oil correlations (Standing, Vasquez-Beggs, Beggs-Robinson) for Rs, Bo and oil viscosity
- gas z-factor (Hall-Yarborough, Dranchuk-Abou-Kassem)
- Havlena-Odeh material balance for OOIP and drive mechanism identification

## Setup

```bash
pip install -e ".[dev]"
pytest
```
